# Mayur Dubey — Portfolio

Redesign of [mayurdubey.com](https://mayurdubey.com). Static single-page site, no build step.

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy

GitHub Pages: Settings → Pages → Deploy from branch `main` / root.

Custom domain: add a `CNAME` file with `mayurdubey.com`, then point the domain’s A/CNAME records at GitHub Pages.

Content is drawn from the existing site (about, career, work titles, contact). Family details from the old About page were left out of this version.
