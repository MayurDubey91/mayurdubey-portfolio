# Mayur Dubey — Portfolio

Personal site for Mayur Dubey. Static single-page site, no build step.

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy

GitHub Pages: Settings → Pages → Deploy from branch `main` / root.

Custom domain: add a `CNAME` file with `mayurdubey.com`, then point the domain’s A/CNAME records at GitHub Pages.
